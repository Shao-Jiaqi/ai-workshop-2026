Materials

Everything used across the two days: the setup you do beforehand, the five decks, and the three practice kits.

Before you arrive

Budget 30 to 45 minutes, and finish it before 09:00 on Tuesday. The two days are compressed — we verify your environment together in Session 1B rather than building it from scratch. The full walkthrough, including Windows and troubleshooting, is in the setup guide.

  • Two accounts — a Claude Code subscription (or API access), and GitHub.
  • A terminal — already installed on macOS; on Windows, install WSL with wsl --install.
  • Python 3.10 or later — check with python3 --version.
  • Claude Code — npm install -g @anthropic-ai/claude-code, then run claude once and log in.
  • Obsidian — free, no account needed, for Session 3A.

Practices

Three hands-on blocks, twenty minutes each, all on the same paper. They compound: A gets you a verified reading, B turns it into two deliverables, C turns it into knowledge that keeps paying back. Full instructions are in the practice guide.

The paper is handed out in the room. All three practices run on one field-experiment manuscript that is unpublished, so it is not distributed here. You will get it at the start of Session 1B, along with a folder to work in. Everything else you need — the kit, the instructions, the slides — is on this page, so you can read ahead.

Install the kit first

Everything runs out of the setup kit — a project memory file, a faithfulness rule, a house Beamer style, the paper-to-slides skill, and a referee subagent. It is adapted from Pedro Sant'Anna's public academic workflow. From the folder holding the paper:

A · Set up, then understand the paper

Session 1B · 20 min · PA_practice.pdf

You have just met the agent; now put it on a real paper. You produce a working setup and a verified one-paragraph overview. Set up, five minutes; orient, eight; verify, six. The habit you keep for the rest of the workshop: never accept a number without naming the table it came from.

B · Paper to talk, then to referee

Session 2 · 20 min · PB_practice.pdf

Two finished artifacts from one paper: present it fairly, then referee it fairly. You produce a faithful talk deck and a referee report, using plan mode, the paper-to-slides skill, and the referee subagent. The instructor's demo is the target — yours need not match slide for slide, only fact for fact.

C · Make the paper compound

Session 3A · 20 min · PC_practice.pdf

A talk is used once; a wiki keeps paying back every time you return to the paper. You produce a mini LLM wiki — an index, a few pages, a log, then a lint pass. The raw source stays read-only; the agent maintains the knowledge pages. Next time you query the wiki instead of re-reading forty pages. The instructor's finished wiki is the answer key — shown in the room after you have built your own.
